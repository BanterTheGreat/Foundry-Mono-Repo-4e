Throwaway design study for a Combat Tracker restyled to match this module's gold-trimmed dark HUD (see persistent-hud-prototype.html / horizontal-hud-prototype.html). Click a row to set the current turn, click the skull to toggle defeated, click an HP number to edit it, use the footer to step rounds.

Reference vs. this version. Kept the reference's shape (nav header, one row per combatant with portrait + init + HP + status icons, round/settings footer) but swapped its blue/grey palette for this module's gold-on-black language: Georgia-serif initiative/HP numerals, the same red HP-bar gradient used elsewhere, and a green glow on the current-turn row instead of a plain highlight colour. Condition icons are round chips instead of the reference's small square glyphs, matching the AP pips used in the persistent HUD.
