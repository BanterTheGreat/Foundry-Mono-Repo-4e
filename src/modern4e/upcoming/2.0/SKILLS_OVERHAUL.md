# Skills handoff (2026-11-23)

Modern 4e 2.0 would give every character a way to use what they know when talking to NPCs. Charisma helps when a character relies on charm, deception, or authority. Other skills help when the approach calls for their expertise. The rulebook and Character Builder still use the current skill list.

## Proposed skill list

The proposed list has 15 skills. It drops Diplomacy and replaces Intimidate with Command.

| Default ability | Skills |
| --- | --- |
| Strength | Athletics |
| Dexterity | Acrobatics, Stealth, Thievery |
| Constitution | Endurance |
| Intelligence | Arcana, Crafting, Medicine, Society |
| Wisdom | Insight, Nature, Perception, Religion |
| Charisma | Bluff, Command |

## How to handle social checks

**Persuasion.** There’s no dedicated persuasion skill. The GM picks the skill that best fits what the character does. Bartering usually calls for Society with Intelligence. If the character is proficient in the chosen skill, add the usual +5. If no skill fits, roll with the ability that best fits the approach. An appeal to goodwill or an attempt to charm someone could use Charisma on its own.

**Bluff (Charisma).** Use Bluff when you want someone to act on something false they believe. Claiming to be an inspector is a Bluff check. If their decision comes down to whether a forged seal looks real, roll Crafting with Intelligence. A successful Bluff can keep someone cooperating for as long as they believe the lie.

**Command (usually Charisma).** Use Command to get someone to act under pressure. You might direct a panicked crowd off a burning pier, rally a wavering crew through sheer resolve, or threaten a guard into stepping aside. The GM can choose another ability if that’s where the pressure comes from. If you bend a gate’s bars to show you can back up a threat, you could roll Command with Strength. A success can get someone to act or comply right away. For a longer commitment, use the persuasion rules above.

## When implementation is approved

Update the rulebook’s skill-check rules and the Character Builder’s skill list. Check backgrounds, feats, sources of proficiency, and skill utility powers for references to Diplomacy and Intimidate. For each one, decide whether Command or another skill fits.

Decide what happens to existing Diplomacy picks and to Command picks that would give a character a proficiency they already have. The proposal for skill proficiency ranks is separate.
