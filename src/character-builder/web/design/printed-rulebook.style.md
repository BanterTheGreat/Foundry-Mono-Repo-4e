Headings: Georgia, falling back to Times New Roman and serif. Normal weight, editorial proportions, slightly tight tracking.

Body and controls: Calibri, falling back to Segoe UI and sans-serif. Comfortable line spacing; small uppercase labels with generous tracking.

Warm ivory surfaces, oxblood emphasis, fine divider lines, mostly square controls, and restrained ornament. Use serif headings for character identity and major sections, with clear sans-serif text for explanations and actions.

The HTML is a self-contained visual reference with local font fallbacks and no remote assets. Sample character text and choices are illustrative, not validated mechanics. Production implementation should follow the selected visual direction rather than copy prototype code.
